# Steppe Meeting Desktop (Tauri + Local AI)

Легковесное кроссплатформенное десктопное приложение для автономной расшифровки совещаний и генерации официальных двуязычных протоколов (русский / казахский) и кратких резюме с использованием локальных моделей **Whisper** и **Ollama** (или любых OpenAI-совместимых эндпоинтов).

---

## Архитектура

- **Десктопный движок**: [Tauri v2](https://tauri.app) (Rust) + WebKit WebView
- **Фронтенд**: React 19 + TypeScript + Vite + Tailwind CSS v4 + Radix UI + Lucide/Phosphor Icons + Zustand
- **Локальный бэкенд**: Автономный FastAPI сервис со встроенным движком генерации протоколов и DOCX (порт 8008)
- **Локальная база данных**: SQLite в пользовательской директории приложения — без необходимости развертывания PostgreSQL
- **Локальное хранилище**: аудио, экспорты, логи и загруженные шаблоны хранятся вне репозитория / `.app`:
  - macOS: `~/Library/Application Support/Steppe Meeting/`
  - Windows: `%LOCALAPPDATA%\Steppe Meeting\`
  - Linux: `${XDG_DATA_HOME:-~/.local/share}/Steppe Meeting/`
  - для разработки путь можно переопределить через `STEPPE_DATA_DIR`
- **Модели AI**:
  - **Речь в текст (STT)**: Local Whisper (`http://localhost:8000/v1/audio/transcriptions` или OpenAI-совместимый Whisper)
  - **Генерация протоколов и резюме (LLM)**: Local Ollama (`http://localhost:11434/v1/chat/completions` — Qwen 2.5, Llama 3.2, Mistral и др.)
  - **AI Copilot (Чат)**: Потоковый локальный ассистент по материалам совещания

## Возможности

1. **3 режима ввода**:
   - Загрузка аудио/видео файлов (MP3, WAV, M4A, MP4, WebM, OGG и др.)
   - Живая запись с микрофона с визуализацией звуковой волны в реальном времени
   - Прямая вставка текста (стенограммы / расшифровки)
2. **Параметры совещания**:
   - Название, дата, выбор языка (KZ / RU / EN / Смешанный)
   - Повестка дня (Күн тәртібі)
   - Список участников с должностями
3. **Генерация официального протокола**:
   - Двуязычный протокол по стандартам делопроизводства (Хаттама / Протокол)
   - Разделение по темам, принятые решения, ответственные лица и сроки
   - Плавающий AI-тулбар: выделите любой фрагмент текста в протоколе, чтобы переписать или улучшить стиль с помощью локальной модели
4. **Краткое содержание (Executive Summary)**:
   - Главные выводы встречи
   - Матрица поручений (Поручение, Ответственный, Срок)
5. **Интерактивный AI Ассистент**:
   - Потоковый чат с ответами по стенограмме и протоколу
   - Быстрые шаблоны: составление драфта письма, список задач, выделение спорных вопросов
6. **Экспорт**:
   - Скачивание официального документа **DOCX** (русский / казахский)
   - Копирование текста протокола и резюме
7. **История и поиск**:
   - Полный локальный архив совещаний с мгновенным поиском по названию и тексту

## Быстрый запуск

### 1. Запуск приложения в один клик:
```bash
cd "steppe-desktop"
./run_app.sh
```

### 2. Запуск вручную (для разработки):
**Терминал 1 (Бэкенд):**
```bash
cd "steppe-desktop/backend"
./run_backend.sh
```

**Терминал 2 (Фронтенд / Tauri):**
```bash
cd "steppe-desktop"
npx vite dev
# или запуск нативного окна:
cd "steppe-desktop/src-tauri"
cargo run
```

## Настройка AI моделей и Whisper STT

В приложении откройте вкладку **"Настройки AI"**:
- **LLM Провайдер (Ollama / Cloud)**:
  - Укажите URL (например, `http://localhost:11434/v1` для Ollama или `https://api.openai.com/v1`, `https://api.deepseek.com/v1`, `https://api.groq.com/openai/v1`).
  - Укажите API-ключ / Bearer-токен (для облачных провайдеров).
  - Нажмите *«Обновить список моделей»* и выберите модель (например, `qwen2.5:latest` или `deepseek-chat`).
- **Whisper STT (Распознавание речи)**:
  - **Режим «Локальный Whisper (Автономно)»**:
    - Нажмите *«Установить среду faster-whisper»* (библиотека и зависимости инференса скачиваются прямо в приложение).
    - Выберите модель (`tiny`, `base`, `small` [рекомендуется], `medium`, `large-v3-turbo`) и нажмите *«Скачать модель»*.
    - Распознавание работает автономно на вашем компьютере без внешних серверов и Docker.
  - **Режим «Внешний сервис (Cloud / API)»**:
    - Выберите быстрый пресет (Groq, OpenAI Whisper, локальный сервер) или введите свой эндпоинт.
    - Введите **API Ключ / Bearer-токен** (для Groq, OpenAI и защищённых сервисов).
    - Укажите имя модели (например, `whisper-large-v3` или `whisper-1`).
- Нажмите *«Сохранить настройки»*.
