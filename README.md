# Steppe Meeting Desktop (Tauri + Local AI)

Легковесное кроссплатформенное десктопное приложение для автономной расшифровки совещаний и генерации официальных двуязычных протоколов (русский / казахский) и кратких резюме с использованием локальных моделей **Whisper** и **Ollama** (или любых OpenAI-совместимых эндпоинтов).

---

## Архитектура

- **Десктопный движок**: [Tauri v2](https://tauri.app) (Rust) + WebKit WebView
- **Фронтенд**: React 19 + TypeScript + Vite + Tailwind CSS v4 + Radix UI + Lucide/Phosphor Icons + Zustand
- **Локальный бэкенд**: Автономный FastAPI сервис со встроенным движком генерации протоколов и DOCX (порт 8008)
- **Локальная база данных**: SQLite (`data/meetings.db`) — без необходимости развертывания PostgreSQL
- **Локальное хранилище**: Файловая система (`data/audio`, `data/exports`) — без S3/SeaweedFS
- **Модели AI**:
  - **Речь в текст (STT)**: Local Whisper (`http://localhost:8000/v1/audio/transcriptions` или OpenAI-совместимый Whisper)
  - **Генерация протоколов и резюме (LLM)**: Local Ollama (`http://localhost:11434/v1/chat/completions` — Qwen 2.5, Llama 3.2, Mistral и др.)
  - **AI Copilot (Чат)**: Потоковый локальный ассистент по материалам совещания

---

## Возможности

1. **3 режима ввода**:
   - Загрузка аудио/видео файлов (MP3, WAV, M4A, MP4, WebM, OGG и др.)
   - Живая запись с микрофона с визуализацией звуковой волны в реальном времени
   - Прямая вставка текста (стенограммы / расшифровки)
2. **Параметры совещания**:
   - Название, дата, выбор языка (KZ / RU / EN / Смешанный)
   - Повестка дня (Күн тәртібі)
   - Список участников с должностями
3. **Генерация официального протокола**:
   - Двуязычный протокол по стандартам делопроизводства (Хаттама / Протокол)
   - Разделение по темам, принятые решения, ответственные лица и сроки
   - Плавающий AI-тулбар: выделите любой фрагмент текста в протоколе, чтобы переписать или улучшить стиль с помощью локальной модели
4. **Краткое содержание (Executive Summary)**:
   - Главные выводы встречи
   - Матрица поручений (Поручение, Ответственный, Срок)
5. **Интерактивный AI Ассистент**:
   - Потоковый чат с ответами по стенограмме и протоколу
   - Быстрые шаблоны: составление драфта письма, список задач, выделение спорных вопросов
6. **Экспорт**:
   - Скачивание официального документа **DOCX** (русский / казахский)
   - Копирование текста протокола и резюме
7. **История и поиск**:
   - Полный локальный архив совещаний с мгновенным поиском по названию и тексту

## Быстрый запуск

### Windows

Нативное окно Tauri на Windows не собирается: захват системного звука реализован
через ScreenCaptureKit, это фреймворк Apple. На Windows приложение работает в
браузере, запись звука при этом остаётся доступной через `getDisplayMedia`
и `getUserMedia`. Rust устанавливать не нужно.

Нужен только **Python 3.10+** и **Node.js 18+**.

```powershell
powershell -ExecutionPolicy Bypass -File .\run_app.ps1
```

Скрипт создаст venv, поставит зависимости, поднимет бэкенд на 8008, фронтенд на
1420 и откроет браузер. Первый запуск занимает несколько минут.

Вручную, в двух окнах PowerShell:

```powershell
# Окно 1
powershell -ExecutionPolicy Bypass -File .\backend\run_backend.ps1

# Окно 2
npm install
npm run dev
```

Затем откройте http://localhost:1420 (лучше в Chrome: в нём надёжнее всего
работает захват звука вкладки).

### macOS и Linux

```bash
./run_app.sh
```

Нативное окно (только macOS):

```bash
cd src-tauri && cargo run
```

## Настройка моделей

Откройте вкладку **«Настройки AI»**. В блоке **«Быстрая настройка»** один клик
настраивает LLM и Whisper вместе:

| Пресет | Что даёт | Ключ |
|---|---|---|
| **Локально** | Полный офлайн: Ollama + локальный Whisper | не нужен |
| **Groq** | `whisper-large-v3-turbo` + Llama 3.3 70B, есть бесплатный тариф | [console.groq.com/keys](https://console.groq.com/keys) |
| **OpenAI** | `whisper-1` + GPT-4o | [platform.openai.com/api-keys](https://platform.openai.com/api-keys) |

Для полностью локальной работы:

- **Ollama**: [ollama.com/download](https://ollama.com/download), затем
  `ollama pull qwen2.5` и `ollama serve`.
- **Whisper**: любой OpenAI-совместимый сервер (faster-whisper-server,
  whisper.cpp, LocalAI) на `http://localhost:8000/v1`.

Эндпоинты, модели и ключи можно задать и вручную в тех же настройках: LLM и
Whisper настраиваются независимо, ключи у них тоже разные.

## Обработка аудио

Перед отправкой в Whisper запись нормализуется через ffmpeg: видеодорожка
отбрасывается, звук сводится в моно 16 кГц, длинные записи режутся на
10-минутные части с последующей сшивкой таймкодов. Это то, что позволяет
обрабатывать часовые совещания, а не только короткие демо.

ffmpeg ставится автоматически как Python-пакет `imageio-ffmpeg`, отдельная
установка в систему не нужна. Если он всё же недоступен, приложение продолжит
работать, но предупредит об этом в настройках.

## Говорящие

Смены говорящего определяются по паузам между сегментами. Это определение
границ реплик, а не опознание голосов: система знает, *где* сменился
говорящий, но не *кто* это. Если при создании совещания указан список
участников, модель дополнительно пытается сопоставить реплики с именами по
обращениям и самопредставлениям.

Любую метку можно переименовать во всей стенограмме одним кликом на вкладке
«Стенограмма». **Проверяйте имена перед экспортом официального протокола.**
