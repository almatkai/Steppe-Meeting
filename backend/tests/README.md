# Тесты

Запускаются без FastAPI и без запущенного сервера, поэтому годятся для быстрой
проверки после правок:

```powershell
cd backend
.\.venv\Scripts\python.exe tests\test_stt.py
.\.venv\Scripts\python.exe tests\test_db.py
```

`test_stt.py` проверяет конвертацию аудио через ffmpeg, нарезку на части,
сшивку таймкодов, заголовок авторизации, определение смен говорящего и
переименование спикеров. Для части проверок нужен ffmpeg (ставится вместе с
`imageio-ffmpeg` из requirements.txt).

`test_db.py` создаёт базу со старой схемой и проверяет миграцию, режим WAL,
восстановление прерванных задач и переименование спикеров через базу.
